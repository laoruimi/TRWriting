# TRWriting 2.0.0

离线网络小说写作桌面应用，支持 Windows 10 / 11（64 位）。

## 运行

- **安装版**：运行 `release/TRWriting-2.0.0-x64-nsis.exe`，可选择安装位置、创建桌面快捷方式。
- **免安装版**：运行 `release/TRWriting-2.0.0-x64-portable.exe`。
- 工作目录中的 `启动TRWriting.cmd` 优先启动桌面版。
- `index.html` 仍可在现代 Edge / Chrome 中作为离线网页版使用。

桌面版本无需 Node.js、Python 或本地服务器。安装包未购买代码签名证书，Windows 可能显示发布者未知。

## 外观和高亮

在右上角齿轮 →「外观与背景」选择午夜墨蓝、石墨深灰、深林夜色或暖白纸张。工作台背景和正文背景支持独立颜色选择，文字随背景明暗自动调整。设置重启后保留。

成对符号的整个内容会分类着色，支持嵌套。例如 `《书中『对白』续文》` 中对白和书名使用不同颜色。未闭合符号着色到当前行末。支持以下 27 对符号：

| 分类 | 符号 |
| --- | --- |
| 对白 | “”、「」、『』、〝〞、英文双引号 |
| 单引号 | ‘’、英文单引号、反引号 |
| 书名 / 角括号 | 《》、〈〉、«»、‹›、<>、＜＞ |
| 方括号 | []、［］、〔〕、｢｣ |
| 系统 / 标记 | 【】、〖〗、〘〙、〚〛 |
| 圆括号 | ()、（）、｟｠ |
| 花括号 | {}、｛｝ |

另外支持中英文冒号后的文字，以及 Unicode 标点符号。英文单词内部的撇号（如 `don't`）不会被当成引号起点。

## 写作功能

- 多章节写作、作品及章节重命名、实时字数和行列位置。
- 打字震动、文字拖影、粒子爆发；中文输入法确认文字后触发。
- 删除字形碎裂、旋转、下坠、消散。
- 12 段连击：NICE、10 GOOD、30 GREAT、60 AMAZING、100 PERFECT、150 EXCELLENT、200 LEGENDARY、300 UNSTOPPABLE、450 OVERDRIVE、650 UNREAL、900 GODLIKE、1200 INFINITE。停笔五秒结算；粘贴和撤销不增加连击。连击仅在爆震开启时显示，采用无边框霓虹样式。
- 燃动电子音（鼓点、低音与上升音阶）与离线真人鼓励短句，段位越高音色层次越丰富、震动和霓虹虚影越强；可独立关闭声音、调节音量并试听。
- 在中间书页按 Ctrl＋鼠标滚轮缩放（60%–200%），目录与工具栏保持原尺寸；点击工具栏百分比恢复 100%，缩放会自动保存。
- 本机 TTF / OTF / WOFF / WOFF2 字体导入，字号、特效强度可调，特效和高亮可关闭。
- 专注模式（Esc 退出）、自动保存、Ctrl+S 保存、全书 TXT 和 JSON 备份导出。

## 数据与迁移

桌面版数据保存在 `%APPDATA%/TRWriting`，与浏览器版本的存档独立。安装版与免安装版共用该目录，卸载默认不删除作品。这里的「免安装」不表示数据跟随 EXE 存放。请定期导出 JSON 备份。

从旧网页版迁移：先在旧网页点击「导出整本备份」，再在桌面版点击「导入作品备份」。导入追加章节、不覆盖现有内容；自选字体文件需重新导入。JSON 导入只导入作品章节，不改变当前外观设置。浏览器清理数据不会影响独立桌面版存档。

超长章节的完整高亮可能增加输入延迟，建议按实际章节拆分。

## 开发与打包

仓库仅包含源码、必要资源和测试；`node_modules/`、`release/`、构建缓存、测试临时文件和本机 IDE 配置不会提交。首次使用源码请先安装 Node.js，再执行以下命令。

```powershell
npm ci
npm start
npm test
npm run test:audio
npm run build
```

使用 Electron / electron-builder，渲染端为原生 HTML / CSS / JavaScript；无远程资源或联网运行依赖。桌面渲染器启用 sandbox 和 contextIsolation，禁用 Node.js 访问。`syntax.js` 是成对符号解析器，`theme.js` 管理主题颜色及文字明暗。

`release/win-unpacked/TRWriting.exe --smoke-test` 在隔离的临时配置目录执行隐藏启动检查，不读取真实作品。


## 1.3 音乐爆震

设置 → 导入音乐 → 输入 BPM（40–300），再设置起拍位置（秒），对准歌曲第一拍。
音乐模式按 BPM 推进半拍片段，200 连击后使用四分之一拍；单段最长 350 毫秒。
片段沿原曲顺序推进并循环，保留原曲音高，切片交叠淡入淡出。快速输入合并播放请求，不截断正在播放的片段，也不反复播放升级短连打；待播时长上限约 450 毫秒。
音乐模式始终关闭评价播报，切回电子音后恢复原先播报设置。停笔仅播放完短暂收尾，不会继续播放整首歌，关闭爆震、关闭声音、切换模式或离开窗口时会停止声音。
支持 Chromium 可解码的 MP3 / WAV / OGG / M4A / FLAC，单文件最大 80 MB，时长 0.1 秒至 10 分钟。
音乐原文件缓存在本机 IndexedDB，重启可用；JSON 作品备份不包含音乐。
真人短句使用 Nice、Great、Perfect、Level up、Congratulations 等，段位名称与播报不完全一一对应。
可独立关闭真人评价，保留连击声。录音作者与 CC BY 4.0 许可可在设置查看，原文随包附于 assets/voice。

## 1.4 码字目标与章节基线

设置中可为当前章节设置独立目标，默认 3000 字，填 0 关闭。书页显示本章进度和达成状态。
章节基线默认每 500 字显示一条虚线，间隔可在 100–10000 字之间调整，也可关闭。按正文非空白 Unicode 字符计数，标点计入；基线跟随排版、滚动和整页缩放，不改动正文。目标随章节自动保存并包含在 JSON 备份中。


## 2.0.0 创作工具

左侧「创作工具」打开检查、搜索、章节、历史、统计、资料、书签、导入导出、专注九个面板。

- 检查：本章红色波浪线提示未闭合引号/括号、重复标点、多余空格及可选段首缩进；黄色提示敏感词。右上角红/黄计数可点击定位。检查仅为启发式提示，不会自动修改正文。
- 词库：内置基础提示词，支持每行一词编辑、TXT/JSON 合并导入和 JSON 导出，最多 10000 词；基础库不代表任何平台审核标准。
- 编辑：每章独立的 150 步撤销/重做，Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z；输入法在确认后记录，粘贴、排版和替换为独立步骤。撤销栈本次运行有效，跨次打开请用历史版本。
- 搜索：Ctrl+F / Ctrl+H；当前章或全书纯文本搜索、英文大小写选项、替换预览和确认；批量替换前保留快照，正文变化后须重新预览。
- 章节：分卷、新增/重命名/删除卷（保留章节）、章节拖动排序/上下移、草稿/已完成/已发布状态；删除进入回收站，可恢复。
- 历史：每 2 分钟自动备份，打开作品、批量替换、章节删除、导入、历史恢复时备份；手动备份、当前章文本差异、整份恢复和历史 JSON 导出。IndexedDB 最多保留 100 份；桌面版另在 `%APPDATA%/TRWriting/backups` 保留最近 100 个独立 JSON 文件，可打开目录或从左下角导入。
- 统计：按本机日期记录今日新增/删除/净增、活跃写作分钟、每日目标及月度日历。历史旧稿不追溯；撤销重做/导入/恢复不累计新增。全书批量替换不计写作量。停笔 60 秒或失焦后暂停计时。
- 资料：卷纲、章节细纲、人物卡、世界观、灵感；与书页并排查看，自动保存。
- 书签：Ctrl+B 在正文光标处添加，可命名为待修改/伏笔提醒，编辑后位置随变化调整。
- 导入导出：TXT/Markdown/DOCX，导入追加并按中文章节标题或 Markdown 标题拆章；DOCX 读取正文文本，不保留复杂图片/表格排版，旧 .doc 不支持。导出全书或当前章，可 ZIP 按章拆分，设置缩进、段间空行及 Word 字体/字号/行距。Word 使用离线 DOCX，不依赖 Office。
- 专注：打字机居中、当前段落突出、番茄钟（1–180 分钟）；可隐藏统计、连击与动效，Esc 退出。番茄钟本次运行有效。

原有整页缩放、字体导入、章节目标/基线与音乐切片模式保留。旧版备份兼容；2.0 整本备份同时携带资料、分卷、书签、词库和统计。导入备份追加章节/资料而不覆盖当前作品；完整回到原状态请使用历史恢复。
